# College Life Adventure Game

## Overview
This is a Python game where players experience a college semester as a student. You make choices about **course load**, **study habits**, and **final semester decisions**. Each decision impacts your **GPA**, **study hours**, **social points**, and **stress level**, leading to different outcomes. The game demonstrates several programming concepts, including branching, logical operators, membership checks, and identity operators.

## Branching Logic and Concepts
1. **Course Planning**
   - Players choose between light, standard, or heavy course loads.
   - The program uses `if/elif/else` statements and comparison operators (`>=`, `<=`) to adjust stats based on GPA and course load.

2. **Study Strategy**
   - Players select a subject to study.
   - The code uses membership operators (`in`, `not in`) to validate input and logical operators (`and`, `or`) to create unique outcomes for each choice.

3. **Final Semester Decisions**
   - Players decide between attending a party or focusing on studying.
   - The game uses identity operators (`is`) on variables and nested `if` statements to determine multiple possible endings.
